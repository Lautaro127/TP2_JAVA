Este repositorio contiene el Trabajo Práctico N°2 de mi carrera, desarrollado en Java para demostrar competencias en programación orientada a objetos mediante la implementación de dos módulos principales: el primero gestiona entidades de Personas y Empleados aplicando validación de DNI con excepciones personalizadas (ExVerificarDNI), uso de colecciones como ArrayList, TreeSet y HashSet con iteradores, y la sobrescritura correcta de métodos equals() y hashCode() junto con la implementación de Comparable; el segundo módulo modela relaciones de herencia e interfaces entre edificios, oficinas y polideportivos, utilizando polimorfismo para almacenar distintos tipos de estructuras en una misma colección, todo ello diseñado para evidenciar el dominio de encapsulamiento, abstracción y manejo de errores en un entorno académico profesional.
